# Fotografía Personal

## Francisco Rafael Torres García

**Materia:** Aplicaciones Web

### Descripción del proyecto
Página web personal dedicada a la fotografía de paisajes y naturaleza, desarrollada con HTML, CSS y JavaScript.

### Actividades del proyecto
1. Crear la estructura HTML.
2. Diseñar el menú de navegación.
3. Agregar un encabezado principal.
4. Incorporar una galería fotográfica.
5. Crear una sección de presentación del equipo.
6. Publicar el proyecto en GitHub Pages.
